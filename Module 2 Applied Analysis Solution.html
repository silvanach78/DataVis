Module 2 Applied Analysis: Signal vs. Noise and Visual Emphasis

Revised Chart

I created a bar chart displaying department performance scores. All departments are shown in a neutral gray color, while the Finance department is highlighted in a contrasting color to draw attention to its lower score. The chart uses a clear, concise title and adds a subtitle that summarizes the insight: “Operations Requires Attention: Lowest Department Performance Score”

1. Design Choices

To improve clarity, I removed the unnecessary elements from Chart A, including the decorative background, redundant legend, excessive gridlines, multiple unrelated colors, long title, and extra annotation. These elements created visual noise and made the main message harder to identify. Removing them improves the signal-to-noise ratio and allows the viewer to focus on the department scores rather than the chart decoration.

2. Visual Emphasis

Compared to Chart B, I added visual emphasis by highlighting the Operations bar. Chart B was readable, but because all bars used the same muted color, the viewer had to scan each value to determine which department required attention. Highlighting Operations uses a pre-attentive attribute, color contrast, to direct attention immediately to the most important data point. All departments are shown in a neutral gray color, while the Finance department is highlighted in a contrasting color to draw attention to its lower score.

3. Managerial Insight

The key insight is that Operations has the lowest performance score at 65, which is noticeably below the other departments. Other departments score between 77 and 81 (at least 20% higher), so Operations appears to be the only department that clearly requires immediate attention.

4. Recommendation

The manager should prioritize a follow-up review of the Operations department to identify the causes of its lower performance. This could include examining workload, staffing, process issues, training needs, or resource constraints before deciding on a corrective action.
