Module 2 Applied Analysis: Signal vs. Noise and Visual Emphasis

You are a manager preparing to present department performance data to a senior leader who needs to quickly identify whether any department requires attention. Two team members created charts using the same dataset, but each chart has design issues that make the message less effective.

Your goal is to evaluate these charts and create a revised version that clearly communicates the most important insight.

Dataset: Department Performance Scores

Chart A: Cluttered Visualization

This chart contains many elements that might appear in real workplace charts, but several of them compete for attention and make the key message less clear.

Chart B: Plain Visualization

This chart is more readable than Chart A, but it does not use emphasis to direct the viewer toward the most important message.

Your Task:

Create one improved chart using the dataset provided. Your chart should:

  • remove unnecessary elements that create clutter or noise
  • use pre-attentive attributes (e.g., color, contrast, position) to clearly highlight the most important message

Then, briefly address the following:

  1. Design choices. Explain what elements from Chart A you chose not to include and why removing them improves clarity.
  2. Visual emphasis.Explain what elements you added or changed compared to Chart B to better direct the viewer’s attention.
  3. Managerial insight. State the key insight the manager should take away from the data.
  4. Recommendation. Provide one concise managerial recommendation based on the insight.

Submission: Upload a Word document with your revised chart and answers for questions 1 through 4.
